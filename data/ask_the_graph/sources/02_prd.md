# PRD: Ask the graph v1

## In scope

- English only
- Three starter question templates
- Read-only
- Citations required on every answer
- Real-time means the UI feels instant (p95 target: snappy), not a new ingest pipeline
- MVP means these three templates, not an open-ended assistant
- The user never has to leave Fusion

## Out of scope

- Write actions (no CMMS, no work orders)
- Languages other than English

## Acceptance

- Given a question about an asset, when data exists, the system returns an answer with at least one citation
- When data does not exist, the system says so
